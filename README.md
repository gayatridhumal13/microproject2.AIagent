# microproject 2: Dual-Capability AI Agent

A smart AI agent built to handle both precise mathematical calculations and general knowledge inquiries using tool routing.

## 🚀 Features
* **Arithmetic Engine:** Automatically solves math problems including addition, subtraction, multiplication, and division.
* **Web Search Integration:** Connects to the internet to fetch real-time information when asked general or current questions.
* **Intelligent Routing:** Decides on its own whether to use a calculator tool or a search tool based on your input.

## 🛠️ Requirements
* Python 3.x
* LangChain (or your chosen framework)
* Search API Token
